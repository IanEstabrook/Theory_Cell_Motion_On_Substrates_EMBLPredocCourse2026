This git repository contains the exercises to form the basis for the theory part of the predoc course 2026. 

The above python files consist of a list of exercises which will guide you through a method to model motion of cells on substrates of different properties. 

If you want to run the files locally in e.g. a jupyter notebook, and have python alreaady installed, download the .zip file of the entire repository and delete the first cell within the main notebook, otherwise visit the URL https://colab.research.google.com/github/IanEstabrook/Theory_Cell_Motion_On_Substrates_EMBLPredocCourse2026/blob/main/add_file_name_later.ipynb

which will open the main notebook in a google colab environment. Run the first cell if using the above link, otherwise ignore it when running locally.
